# Meowdoku Overlay Solver

Private Android app for my personal use.

Status: Phase 1 complete.

Phase 1 provides:

- A minimal Android application project.
- Notification and display-over-other-apps permission handling.
- A foreground service that displays a floating `SOLVE` button.
- No screen capture or solve behavior yet.

The project uses Android Gradle Plugin 9.2.1, Gradle 9.4.1, Java 17, and Android SDK 36. Open it in Android Studio or run `gradle :app:assembleDebug` with those tools installed.
